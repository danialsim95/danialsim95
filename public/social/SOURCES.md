# Social Logo Sources

- `github.svg`: unmodified black Invertocat SVG from the [official GitHub logo package](https://brand.github.com/GitHub_Logos.zip). [Usage guidelines](https://brand.github.com/foundations/logo).
- `linkedin.svg`: monochrome `linkedin-plain.svg` from [Devicon](https://github.com/devicons/devicon/blob/v2.17.0/icons/linkedin/linkedin-plain.svg). The [official LinkedIn downloads](https://brand.linkedin.com/downloads) provide PNG rather than SVG in the inspected icon package. [Usage guidelines](https://brand.linkedin.com/en-us).
